# CHAFIK CREDIT – CHAFIK-TECH

تطبيق Android أولي لإدارة الزبائن والديون والتسديدات، باللغة العربية ويعمل محليًا دون إنترنت.

## الوظائف الموجودة
- إضافة زبون مع الاسم ورقم الهاتف.
- تسجيل أكثر من دين لكل زبون.
- تسجيل تسديدات للزبون مع منع تجاوز الرصيد المتبقي.
- إجمالي الديون والتسديدات والمتبقي.
- قائمة زبائن مع البحث وملف لكل زبون.
- سجل التسديدات.
- قاعدة SQLite محلية على الهاتف.

## بناء APK من GitHub
1. أنشئ مستودعًا جديدًا على GitHub باسم `ChafikCredit`.
2. ارفع محتويات هذا المجلد إلى جذر المستودع (لا ترفع المجلد الأب نفسه).
3. افتح تبويب Actions.
4. اختر `Build CHAFIK CREDIT APK` ثم `Run workflow`، أو انتظر البناء بعد رفع الملفات إلى فرع main.
5. بعد نجاح البناء، افتح نتيجة التشغيل وانزل إلى Artifacts.
6. نزّل `CHAFIK-CREDIT-debug` واستخرج ملف APK.

## ملاحظات مهمة
- هذه نسخة أولية عملية وليست نسخة نهائية مختبرة على كل الأجهزة.
- لا تحذف بيانات التطبيق أو تمسح بياناته قبل أخذ نسخة احتياطية؛ قاعدة البيانات محلية.
- اختبر الحسابات على بيانات تجريبية قبل إدخال بيانات حقيقية.
- لا يحتوي المشروع حاليًا على تسجيل دخول أو نسخ احتياطي/استرجاع أو تصدير Excel.
